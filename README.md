# Transcriber

Локальна програма для перетворення мовлення з відео на текст. Працює повністю офлайн (після першого завантаження моделі), файли нікуди не відправляються.

Побудована на [faster-whisper](https://github.com/SYSTRAN/faster-whisper) з моделлю Whisper `large-v3` та GUI на PySide6.

## Можливості

- Вибір відео (`.mp4`, `.mov`, `.mkv`)
- Результат у вигляді тексту (`.txt`) та/або субтитрів (`.srt`)
- Вибір мови: українська, англійська або автовизначення
- Вибір папки та назви файлу результату
- Прогрес обробки у вікні
- Автоматичний вибір пристрою: NVIDIA GPU (CUDA), якщо доступна, інакше процесор
- Автоматичне завантаження моделі при першому запуску

## Платформи

| Платформа | Обробка | Швидкість |
|---|---|---|
| Linux + NVIDIA GPU | відеокарта | швидко |
| Linux без NVIDIA | процесор | повільно |
| macOS (Apple Silicon) | процесор | повільно |

На процесорі обробка в кілька разів довша, ніж на відеокарті. Годинне відео може оброблятися десятки хвилин.

## Перший запуск

При першому запуску програма завантажує модель (~3 ГБ) з Hugging Face. Потрібен інтернет, це відбувається лише один раз. Далі програма працює офлайн.

## Запуск з коду (Linux)

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python window.py
```

Для роботи на NVIDIA GPU потрібні бібліотеки CUDA 12 (cuBLAS, cuDNN). Якщо їх немає, програма автоматично перейде на процесор.

Запуск без вікна, з терміналу:

```bash
python transcribe.py шлях/до/відео.mp4
```

## macOS: як відкрити програму

Програма не підписана сертифікатом Apple, тому macOS заблокує перший запуск.

1. Розпакуйте `Transcriber-macos-arm64.zip`.
2. Спробуйте відкрити `Transcriber.app`. З'явиться попередження, натисніть «Готово».
3. Відкрийте **Системні параметри → Конфіденційність і безпека**, прокрутіть донизу і натисніть **«Усе одно відкрити»** біля повідомлення про Transcriber.

Або в Терміналі:

```bash
xattr -dr com.apple.quarantine /шлях/до/Transcriber.app
```

## Структура

- `transcribe.py` — ядро: вибір пристрою, завантаження моделі, розпізнавання, запис `.txt` / `.srt`
- `window.py` — графічний інтерфейс
- `assets/` — зображення інтерфейсу
